まずは、something fun と some kind of の違いについてです。

Let's do something fun this weekend.

ここがポイントです。

something の後ろに形容詞を置く形は、モノやコトの中身、つまり質そのものを曖昧にします。一方で some kind of プラス名詞の形は、名詞が何であるかは決まっているけれど、その種類やカテゴリーを曖昧にします。

もう一度聞いてみましょう。

It felt like some kind of joke.

続いて、この違いを尋ねる表現を3つのバリエーションで聞いてみましょう。

I wanna know the difference between something fun and some kind of.

I'd like to understand the difference between something fun and some kind of.

What's the actual difference between something like something fun and some kind of?

次は、冗談への切り返し表現です。新しいグループに入ったときに、忠誠の証として写真を送れと冗談を言われた場面を想定しています。

Oh really?! Show me how it's done then, senpai!

Oh, is that so? Then please, lead by example first.

Oh yeah? Let's see you do it first then, big guy!

最後に、lead by example という表現を使った例文をもう一つ聞いてみましょう。

You should lead by example if you want people to trust you.
